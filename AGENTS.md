# Instruccions per als agents de codi

Llegeix [CLAUDE.md](CLAUDE.md) per al context i les convencions del projecte. Per a un defecte detectat durant una tasca, segueix [docs/gestio-bugs.md](docs/gestio-bugs.md): diferencia els errors de la implementació en curs dels bugs preexistents, informa la persona responsable dels possibles bugs fora d'abast i no creïs issues ni ampliïs la tasca sense confirmar-ho amb ella.

Abans d'atribuir un error al projecte, comprova l'entorn: fes servir la versió de Node indicada a `.nvmrc` (ara, 22) i verifica-la amb `node -v`. Les sessions de terminal poden començar amb una altra versió; activa la correcta a cada sessió de proves. Si un error només apareix amb una versió no admesa, no el registris com a bug del projecte.
